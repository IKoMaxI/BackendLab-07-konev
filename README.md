# Lab7

ASP.NET Core Web API с пользовательскими middleware.

## Запуск

```bash
dotnet run
```

Приложение запускается по адресу `http://localhost:5029`.

Корневой адрес `/` открывает страницу со ссылками на проверочные маршруты.

Доступные маршруты:

- `GET /ping`
- `GET /trace`
- `GET /blocked/test`
- `GET /error`
